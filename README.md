# Color Mix for CS50
#### Video Demo:  <https://youtu.be/p4tzqYGXZ-A>
#### Description:

Color Mix for CS50 is an interactive web application that allows users to experiment with color mixing in a simple and visual way.

The project was developed as an independent application inspired by Harvard's CS50 course. Its goal is to provide an intuitive interface where users can select colors, adjust mixing ratios, and see the results in real time.

The application also displays the HEX and RGB codes of the resulting colors, allowing users to view and copy these values for use in other projects.

## Features

The project includes the following features:

- **Color Mixer:** Allows users to select two colors and view the resulting mixed color.
- **Adjustable Color Ratio:** Allows users to control the proportion of each color used in the mixture.
- **HEX and RGB Codes:** Displays the corresponding values of the resulting color.
- **Copy Color Codes:** Allows users to copy color codes to the clipboard.
- **Random Color Mix:** Provides the option to experiment with random color combinations.
- **Palette Generator:** Displays collections of colors that can serve as inspiration.
- **Interactive Palettes:** Allows users to select colors from palettes and use them in the color mixer.
- **Responsive Design:** Adapts the interface to different screen sizes, including desktop computers and mobile devices.

## Technologies Used

The project was developed using the following technologies:

- **HTML5:** Used to structure the content and interface elements.
- **CSS3:** Used to define the layout, colors, typography, visual effects, and responsive design.
- **JavaScript:** Used to implement the color-mixing logic, interactions, and dynamic updates to the page.
- **Google Fonts:** Used to load typefaces for the interface.

## Project Files

The project is organized into the following files:

- `index.html`: Contains the main structure of the application, including its interface components.
- `styles.css`: Contains the styling rules responsible for the visual appearance and responsiveness of the interface.
- `script.js`: Contains the JavaScript logic responsible for the application's features and interactions.
- `README.md`: Provides the project description, features, technologies, and learning goals.
- `DESIGN.md`: Documents design decisions and possible future improvements.

## Implementation

The application uses HTML to organize the page elements, CSS to define their appearance, and JavaScript to control interactive behavior.

Color mixing is calculated using the RGB values of the two selected colors. The chosen ratio determines how much each color contributes to the final result.

After the calculation, the application updates the visual representation of the resulting color and displays its values in HEX and RGB formats.

JavaScript also handles button interactions, random color generation, color selection from palettes, and copying color codes to the clipboard.

The interface was designed to make navigation simple and provide an intuitive user experience.
