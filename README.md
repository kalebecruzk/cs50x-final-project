# Color Mix for CS50

O Color Mix for CS50 é uma aplicação web interativa desenvolvida como projeto final do curso CS50 de Harvard. A aplicação permite selecionar duas cores, ajustar suas proporções, visualizar a mistura em tempo real e consultar ou copiar os códigos HEX e RGB resultantes.

O projeto conta com recursos como geração aleatória de cores, criação de paletas interativas e design responsivo para computadores e dispositivos móveis.

**Tecnologias utilizadas:**
- HTML5
- CSS3
- JavaScript
- Google Fonts

**Desenvolvimento:**

O arquivo `index.html` foi desenvolvido com base em pesquisas e estudos realizados durante o processo de criação. Os arquivos `styles.css` e `script.js` foram desenvolvidos com o auxílio do ChatGPT, incluindo a implementação dos estilos visuais, funcionalidades e interações da aplicação.

O projeto teve como objetivo aplicar conhecimentos de desenvolvimento web, lógica de programação, manipulação do DOM e representação de cores nos formatos RGB e HEX.
